# اخبار هوشمند — Smart News Telegram Bot

ربات فارسی تلگرام برای دریافت اخبار با **احراز هویت از طریق اشتراک شماره تلفن**، **تنظیمات کاربری**، **دسته‌بندی خبری**، **خلاصه هوشمند (اختیاری)** و **ارسال زمان‌بندی‌شده**.

> ⚠️ **امنیت:** توکن ربات را هرگز در ریپازیتوری کامیت نکنید. اگر توکن در چت یا جای عمومی ارسال شده، در [@BotFather](https://t.me/BotFather) با دستور `/revoke` آن را تمدید کنید و توکن جدید را فقط در فایل `.env` قرار دهید.

---

## امکانات

- 🔐 **ثبت‌نام و احراز هویت** با دکمهٔ رسمی `request_contact` تلگرام (فقط شمارهٔ خود کاربر پذیرفته می‌شود).
- 📰 **دریافت آخرین اخبار** از منابع RSS عمومی، با حذف خبرهای تکراری و مرتب‌سازی بر اساس زمان.
- 🤖 **خلاصه هوشمند** با هر endpoint سازگار با OpenAI؛ در نبود کلید، گزیدهٔ متنی ارسال می‌شود.
- ⏰ **ارسال خودکار** در نوبت‌های صبح/ظهر/شب (پیش‌فرض: `08:00`, `13:30`, `20:00` به وقت `Asia/Tehran`).
- ⚙️ **تنظیمات واقعی**: نحوهٔ دریافت، روشن/خاموش کردن اعلان‌ها، انتخاب دسته‌بندی‌ها.
- 📋 **اطلاعات حساب کاربری** با شمارهٔ ماسک‌شده، تاریخ عضویت شمسی و خروج از حساب.
- 🗂 دسته‌بندی‌های پیش‌فرض: عمومی، سیاسی، اقتصادی، فناوری، **هوش مصنوعی**، ورزشی، بین‌الملل، سلامت.
- 🤖 **اخبار اختصاصی هوش مصنوعی**: فیدهای تخصصی AI + فیلتر هوش مصنوعی روی منابع فارسی عمومی.
- 🧪 تست‌های واحد، Docker، systemd و CI.

## 🛠 پنل ادمین

یک دکمهٔ **«🛠 پنل ادمین»** به کیبورد اصلی اضافه شده است. با زدن آن:

1. ربات درخواست **احراز هویت با شماره تلفن** می‌کند (دکمهٔ رسمی اشتراک شماره).
2. به‌صورت پیش‌فرض **هر شماره‌ای** می‌تواند احراز هویت کند و وارد پنل شود.
3. پس از ورود، منوهای شیشه‌ای (inline) نمایش داده می‌شوند:

| منو | کارکرد |
|---|---|
| ➕ افزودن خبر | دریافت عنوان → متن → لینک (اختیاری) → دسته‌بندی، سپس ذخیره در دیتابیس |
| 📰 لیست اخبار | لیست صفحه‌بندی‌شدهٔ اخبار همراه با تعداد بازدید هر خبر |
| 👥 لیست کاربران | خواندن کاربران از دیتابیس با صفحه‌بندی (نام، یوزرنیم، شمارهٔ ماسک‌شده، وضعیت اعلان) |
| 📊 آمار و بازدیدها | تعداد کاربران، اخبار، مجموع بازدیدهای یکتا و پربازدیدترین اخبار |
| 📣 ارسال همگانی | ارسال یک خبر اختصاصی به همهٔ کاربران |
| 🗑 حذف خبر | حذف خبر و بازدیدهای ثبت‌شدهٔ آن |
| 🚪 خروج از پنل ادمین | حذف دسترسی ادمین |

### نمایش اخبار ادمین در ربات اصلی

اخباری که ادمین اضافه می‌کند در همان ربات اصلی و لابه‌لای اخبار دریافتی کاربر نمایش داده می‌شوند:

- در دستور `/news` و دکمهٔ «دریافت آخرین اخبار»
- در ارسال‌های زمان‌بندی‌شدهٔ روزانه
- فقط برای کاربرانی که آن دسته‌بندی را فعال کرده‌اند
- همراه با دکمهٔ «👁 مشاهده کامل خبر»

### شمارش بازدیدها

هر بازدید به‌صورت **یکتا به‌ازای هر کاربر** در جدول `news_views` ثبت می‌شود؛ یعنی اگر یک کاربر چند بار خبر را ببیند، فقط یک بازدید شمرده می‌شود. ادمین تعداد بازدید هر خبر را در «لیست اخبار» و «آمار و بازدیدها» می‌بیند.

### محدودسازی دسترسی ادمین (توصیه‌شده)

> ⚠️ **هشدار امنیتی:** در حالت پیش‌فرض هر کسی با اشتراک شماره می‌تواند ادمین شود. برای محیط واقعی حتماً یکی از این دو را تنظیم کنید:

```env
# فقط این شماره‌ها بتوانند ادمین شوند
ADMIN_PHONES=+989121234567,+989351112233

# یا فقط این شناسه‌های تلگرام
ADMIN_IDS=123456789
```

اگر `ADMIN_PHONES` خالی باشد، احراز هویت با هر شماره‌ای آزاد است (مطابق درخواست اولیه).

## اجرای سریع

```bash
git clone <YOUR_REPO_URL> smart-news-bot
cd smart-news-bot

python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env
# فایل .env را ویرایش کنید و BOT_TOKEN را قرار دهید.

python -m bot
```

ربات به‌صورت پیش‌فرض با **long polling** اجرا می‌شود و نیازی به دامنه/وب‌هوک ندارد.

## تنظیمات `.env`

| متغیر | پیش‌فرض | توضیح |
|---|---|---|
| `BOT_TOKEN` | — | توکن ربات از BotFather |
| `BOT_NAME` | `اخبار هوشمند` | نام نمایشی در پیام‌ها |
| `ADMIN_IDS` | خالی | شناسه‌های عددی مدیر، جداشده با کاما |
| `DB_PATH` | `data/bot.db` | مسیر SQLite |
| `TIMEZONE` | `Asia/Tehran` | منطقهٔ زمانی ارسال‌ها |
| `SCHEDULE_TIMES` | `08:00,13:30,20:00` | نوبت‌های ارسال روزانه |
| `SOURCES_FILE` | `sources.json` | فایل منابع خبری |
| `NEWS_PER_DIGEST` | `8` | تعداد خبر در هر بولتن |
| `CUSTOM_NEWS_LIMIT` | `5` | تعداد اخبار اختصاصی ادمین در هر ارسال |
| `ADMIN_PHONES` | خالی | محدودسازی احراز هویت ادمین به شماره‌های مشخص |
| `FEED_TIMEOUT` | `12` | timeout هر فید (ثانیه) |
| `CACHE_TTL` | `300` | کش خبرها (ثانیه) |
| `OPENAI_API_KEY` | خالی | کلید AI؛ خالی = گزیدهٔ متنی |
| `OPENAI_BASE_URL` | `https://api.openai.com/v1` | endpoint سازگار با OpenAI |
| `OPENAI_MODEL` | `gpt-4o-mini` | مدل خلاصه‌سازی |

## منابع خبری

فایل `sources.json` شامل دسته‌بندی‌ها و فیدهای RSS است. می‌توانید فیدهای دلخواه (مثلاً خبرگزاری‌های داخلی) را اضافه کنید:

```json
{
  "categories": [
    {
      "id": "general",
      "title": "عمومی",
      "emoji": "📰",
      "feeds": [
        {"name": "ایرنا", "url": "https://www.irna.ir/rss"}
      ]
    }
  ]
}
```

> دسترسی به برخی فیدهای داخلی ممکن است از سرورهای خارج از ایران محدود باشد. ربات در صورت خطای یک فید، بقیهٔ منابع را ادامه می‌دهد.

### 🤖 دسته هوش مصنوعی

دستهٔ `ai` با عنوان **«🤖 هوش مصنوعی»** به `sources.json` اضافه شده است و شامل این منابع است:

- فید تخصصی هوش مصنوعی «یک آی‌تی‌نویس»
- فید برچسب هوش مصنوعی «بیگ بنگ»
- فیلتر کلیدواژه‌های هوش مصنوعی روی یورونیوز فارسی، ایران اینترنشنال، BBC فارسی و ایندیپندنت فارسی

کلیدواژه‌ها فقط روی **عنوان** خبر اعمال می‌شوند تا خبرهای نامرتبط وارد دسته نشوند؛ برای فیدهای برچسب‌دار، برچسب «هوش مصنوعی» نیز پذیرفته می‌شود.

کاربرانی که دسته‌بندی آن‌ها روی «همه» است، به‌صورت خودکار اخبار هوش مصنوعی را هم دریافت می‌کنند. اگر کاربر قبلاً دسته‌های مشخصی را انتخاب کرده باشد، باید از مسیر **تنظیمات ← انتخاب دسته‌بندی‌ها** گزینهٔ **🤖 هوش مصنوعی** را فعال کند. در پنل ادمین هم هنگام افزودن خبر می‌توان دستهٔ «🤖 هوش مصنوعی» را انتخاب کرد.

## systemd

فایل نمونه: `deploy/smart-news-bot.service`

```bash
sudo cp deploy/smart-news-bot.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now smart-news-bot
sudo journalctl -u smart-news-bot -f
```

مسیرها را در فایل سرویس مطابق سرور خود تغییر دهید.

## حریم خصوصی و امنیت

- شماره تلفن فقط برای احراز هویت ذخیره می‌شود و در پیام‌های خبری/AI ارسال نمی‌شود.
- در پنل حساب، شماره به‌صورت ماسک‌شده نمایش داده می‌شود.
- فایل‌های `.env` و `data/` در `.gitignore` هستند.
- دسترسی فایل دیتابیس به `0600` محدود می‌شود.
- برای تولید، توکن را محرمانه نگه دارید و در صورت افشا، آن را revoke کنید.
